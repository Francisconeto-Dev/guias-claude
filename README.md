# Guias de Claude Code

Site estático com os guias de Claude Code de Francisco Neto (@francisconeto.dev).

- `index.html`: lista dos guias.
- `mcp/index.html` e `lentes/index.html`: os guias.
- `assets/`: assinatura (`assinatura.svg`), fotos do autor e imagens de compartilhamento (`og-*.png`, 1200x630).

## Foto do autor

A foto já está no site (28/10/2026):

- `assets/autor-inteiro.jpg` (retrato inteiro, 899x1200): capa de cada página e imagens de compartilhamento.
- `assets/autor.jpg` (rosto, 400x400): avatar pequeno no bloco "Siga" no fim dos guias.

Para trocar a foto, basta substituir esses dois arquivos mantendo o mesmo nome e a mesma proporção (3:4 e quadrada). Depois disso, gere de novo as imagens `og-*.png`, porque a foto também está nelas.
