Todo servidor MCP diz, ferramenta por ferramenta, se ela só lê, se é seguro repetir e se pode destruir. Dá para ler isso antes de ligar o servidor no Claude Code, em menos de um minuto.

O que eu fiz com isso

Liguei o servidor oficial de arquivos do projeto MCP numa pasta de teste e pedi a lista de ferramentas com as anotações.

  • 14 ferramentas. 10 só leem. 4 escrevem: write_file, edit_file, create_directory e move_file.
  • Das 4 que escrevem, 2 se declaram seguras para repetir (write_file e create_directory). edit_file e move_file, não.
  • Pedi um arquivo fora da pasta que eu liberei: Access denied - path outside allowed directories. O conteúdo não foi lido.

Por que isso importa: desde a versão 2.1.307 do Claude Code (21/10/2026), se a conexão com um servidor MCP por HTTP cai no meio de uma chamada, ele só repete ferramenta que se declara só leitura ou segura para repetir. Quem declara é o servidor.

Pré-requisitos

  • Node.js 22 (foi o que eu usei).
  • Python 3, só com a biblioteca padrão.
  • Uma pasta vazia só para o teste. Nunca dentro de um projeto de verdade.

Passo a passo

  1. Crie a pasta do teste e a pasta que o servidor vai enxergar:
Terminal
mkdir -p teste-mcp/alvo teste-mcp/srv
cd teste-mcp
echo "arquivo de teste" > alvo/nota.txt
  1. Instale o servidor só nessa pasta, sem rodar script de instalação:
Terminal
cd srv
npm init -y
npm install --ignore-scripts @modelcontextprotocol/server-filesystem@1.0.0
cd ..
  1. Antes de rodar, leia o código instalado. Eu procurei sinais de rede e de processo filho:
Terminal
grep -rnE "child_process|http|net|fetch|exec|spawn|eval" srv/node_modules/@modelcontextprotocol/server-filesystem/dist/

No meu teste: nenhuma ocorrência.

  1. Salve este cliente como cliente_mcp.py dentro de teste-mcp/. Ele liga o servidor, lista as ferramentas com as anotações e faz duas leituras, uma dentro e uma fora da pasta liberada:
Python
import json, subprocess, os

AQUI = os.path.dirname(os.path.abspath(__file__))
SRV = os.path.join(AQUI, "srv/node_modules/@modelcontextprotocol/server-filesystem/dist/index.js")
PASTA = os.path.join(AQUI, "alvo")

p = subprocess.Popen(["node", SRV, PASTA], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                     stderr=subprocess.PIPE, text=True)
n = 0
def pedir(metodo, params=None):
    global n
    n += 1
    p.stdin.write(json.dumps({"jsonrpc": "2.0", "id": n, "method": metodo, "params": params or {}}) + "\n")
    p.stdin.flush()
    while True:
        msg = json.loads(p.stdout.readline())
        if msg.get("id") == n:
            return msg

def avisar(metodo):
    p.stdin.write(json.dumps({"jsonrpc": "2.0", "method": metodo}) + "\n"); p.stdin.flush()

ini = pedir("initialize", {"protocolVersion": "2025-06-18", "capabilities": {},
                           "clientInfo": {"name": "laboratorio", "version": "0.1"}})
info = ini["result"]["serverInfo"]
print(f"Servidor: {info['name']} {info['version']}")
avisar("notifications/initialized")

ferramentas = pedir("tools/list")["result"]["tools"]
print(f"\n{len(ferramentas)} ferramentas expostas:\n")
print(f"{'ferramenta':28} {'só lê':6} {'repetir é seguro':17} {'pode destruir':13}")
le = escreve = 0
sim = lambda v: "sim" if v else "não"
for f in ferramentas:
    a = f.get("annotations", {})
    so_le = a.get("readOnlyHint", False)
    idem = a.get("idempotentHint", False)
    dest = a.get("destructiveHint", not so_le)
    le += so_le; escreve += (not so_le)
    print(f"{f['name']:28} {sim(so_le):6} {sim(so_le or idem):17} {sim(dest) if not so_le else 'não':13}")
print(f"\nSó leitura: {le} | Escrevem: {escreve}")

r = pedir("tools/call", {"name": "read_text_file", "arguments": {"path": os.path.join(PASTA, "nota.txt")}})
print("\nDentro da pasta:", json.dumps(r.get("result", r.get("error")), ensure_ascii=False)[:200])
r = pedir("tools/call", {"name": "read_text_file", "arguments": {"path": os.path.expanduser("~/.zshrc")}})
print("Fora da pasta:", json.dumps(r.get("result", r.get("error")), ensure_ascii=False).replace(os.path.expanduser("~"), "~")[:220])
p.terminate()
  1. Rode:
Terminal
python3 cliente_mcp.py
  1. Leia a tabela. Tudo que aparece com "só lê: não" mexe nos seus arquivos. Se "repetir é seguro" estiver "não", uma repetição pode estragar o que já foi feito.
  2. Na hora de ligar de verdade, passe para o servidor só a pasta do projeto, nunca a sua pasta pessoal inteira. É o mesmo argumento do passo 4 (PASTA): o servidor recusa tudo fora dela, como mostrou a leitura de fora.

Erros que eu tive e como resolvi

  • A versão mais nova do servidor (2.0.0, de 19/10/2026) pede Node.js 24, e eu estava no 22. Usei a 1.0.0, a última da linha anterior, com as mesmas 14 ferramentas.
  • O teste de leitura fora da pasta mostra o caminho completo da sua pasta pessoal na resposta. No cliente, troquei o começo do caminho por ~ antes de imprimir, para o print não expor nome de usuário.

Limites

  • Anotação é declaração do servidor. Um servidor mal feito pode marcar como "só leitura" uma ferramenta que escreve. Por isso o passo 3 vem antes.
  • Este servidor roda por stdio. A regra de repetição da 2.1.307 vale para MCP por HTTP; o teste mostra as anotações, não a repetição acontecendo.
  • Não testei a ligação desse servidor dentro de uma sessão do Claude Code.
